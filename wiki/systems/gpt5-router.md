# GPT-5 real-time router
Source: OpenAI GPT-5 System Card (Aug 2025) plus press coverage. Locus: provider-internal ([[industry-landscape]]).

- One product name hides several models (gpt-5-main, -main-mini, -thinking, -thinking-mini, and a pro variant). A **real-time router** chooses per request using conversation type, complexity, tool needs and explicit intent ("think hard about this").
- Per the card, it is **trained continuously on real usage signals**: when users switch models, preference rates, and measured correctness ([[personalized-routing]], [[gap-learning-from-logs]]).
- After usage limits are reached, mini variants take over (budget-driven routing).
- **Reception.** A user backlash over loss of control and perceived quality drops followed launch, and OpenAI restored manual model choice. This is the clearest real-world evidence for [[gap-transparency-and-control]].
- Evaluated as a router on [[routerarena]] (initial board: 62.7 accuracy).
