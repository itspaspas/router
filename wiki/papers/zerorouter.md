# Breaking Model Lock-in: Cost-Efficient Zero-Shot LLM Routing via a Universal Latent Space
arXiv:2601.06220 (Jan 2026). Category: [[cold-start-and-model-representation]].

**Idea.** Learn a model-agnostic latent space of *query difficulty*, decoupled from model profiles. A new model is onboarded by profiling it on a small set of anchor queries, not by broad benchmarking.
**Evidence (authors).** Largest gains on unseen datasets.
**Open.** How anchor queries should be chosen, and how robust profiles are for qualitatively new models ([[gap-nonstationary-pools]]).
